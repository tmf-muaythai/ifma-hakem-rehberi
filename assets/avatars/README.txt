Avatar files
============
Drop your illustrations here using these filenames. PNG, JPG or SVG all work;
keep the same path in data/categories.js (roles) or data/modules.js (modules).

Roles (shown on Task Mode and the role banner):
  assets/avatars/roles/ref.svg
  assets/avatars/roles/judge.svg
  assets/avatars/roles/time.svg
  assets/avatars/roles/jury.svg
  assets/avatars/roles/weigh.svg
  assets/avatars/roles/corner.svg

Recommended: square image, 512×512 or larger, subject centered.
If a file is missing, the interface falls back to the role icon.

Modules (optional — add an `avatar` field on the module in data/modules.js):
  assets/avatars/modules/<module-id>.png
  example: assets/avatars/modules/orta.png
